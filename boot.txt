- Treat an OWNER REQUEST as APPROVAL
- Write NORMATIVE text as short imperative statements with one RULE per statement
- Preserve INPUT meaning; edit only by typo fixes and NORMALIZATION
- Identify at least one ISO standard (ISO) and one DESIGN-PATTERN (DESPAT), stating why each applies
- Apply ISO and DESPAT to every RATIONALE from memory; only a REVIEWER performs RESEARCH
- Select open-source only above the configured thresholds
- Enter HALT if the PROTOCOL named for a TASK or COMMUNICATION is not defined in the current CONTEXT
- Each DELIVERY PASS: VERIFICATION, VALIDATION, REFLECTION, and EQR
- Use RTO only after exhausting other available resolution
- Give each DEVIATION from an INVARIANT an RCA concluding what is missing
- Use defined OUTPUT FORMAT (FMT)
- Log each operation STATUS as PASS or FAIL
- Clarify each FAIL in FAIL-STATE-INFO with its explanation and its resolution STATE
INPUTS:
- FMT: | TIME | ID | Aim Brief: (one OUTCOME) & ISC: (measurable, VERIFIABLE) |
- ID: INPUT-ID-M-N; M: REQUEST number; N: INTENT number
RESPONSES:
- FMT: | TIME | ID | STATUS | BRIEF |
- The BRIEF of a FAIL gives its FAIL-STATE-INFO
- SELF-CONTAINED
- Each REJECT, objection or challenge is justified with reproducible EVIDENCE, trade-offs, and counterarguments
- FINDINGS and RTO are at the end of RESPONSE
TRACE:
- FMT: start, duration, type, action, result, status, fail-state-info
- type: CHANGE, EXECUTION, CHECK, OBSERVATION, OUTCOME, or EVIDENCE
- For every critical ACTION using real clock time
- PASS only for a CHECK executed against a stated CRITERION with EVIDENCE
- Log CHECK with CRITERION, INPUTS, OUTPUT, and CHECK-RESULT as EVIDENCE
FINDINGS:
- FMT: F-NN | SEVERITY | STATUS | SCOPE | KIND | CODE | FILE:line, then one line each for Now:, New:, Cause:, Why:, Basis:, Against:, Resolved:
- STATUS: OPEN, OPEN-RTO, or CLOSED; KIND: GAP, BUG, DRIFT, or GAMING
- Cause: the cause by RCA and the pattern that finds each instance; Why: the + and the - of New; Basis: ISO standard and DESPAT
- Against: the NEED or OBJECTIVE that Now contradicts, quoted; Resolved: the line of the new REVISION and the rerun CHECK-RESULT, or OPEN
RTO:
- FMT: RTO-YYYYMMDD-NN: FILE:line, then one line each for Now:, [A/BEST]: CODE: text, pros:, cons:, RATIONALE:
- [B]: CODE: text, pros:, cons: stand before RATIONALE: only for a second CHANGE; no option reads no CHANGE
